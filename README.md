# Sikandar Tariq — Personal Portfolio

A modern Next.js portfolio for Sikandar Tariq:
- Computer Science Teacher
- Business Owner
- Game Developer
- Graphic Designer
- Marketing Manager

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
npm start
```

## Customize

Edit the content inside:
- `components/Hero.jsx`
- `components/About.jsx`
- `components/Skills.jsx`
- `components/Projects.jsx`
- `components/Experience.jsx`
- `components/Contact.jsx`

Replace the placeholder email/GitHub/LinkedIn links in `Contact.jsx`.
